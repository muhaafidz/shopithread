How to Install the Extension on Google Chrome

It takes less than 1 minute to start using ShopiThread.

STEP 1

Download the Release ZIP File

Download the shopee-affiliate-threads-extension-v1.0.0.zip file, then extract it to a folder on your computer.

STEP 2

Open the Chrome Extensions Menu

Open the Chrome browser, type chrome://extensions in the address bar, and enable the Developer Mode toggle in the top-right corner.

STEP 3

Click Load Unpacked

Click the Load unpacked button, then select the extracted folder. The extension is instantly active and ready to use!
